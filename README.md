# sklearn-fix-sandbox

A small sandbox containing one real, self-contained function adapted from
[scikit-learn](https://github.com/scikit-learn/scikit-learn)
(`sklearn/utils/validation.py::check_random_state`, BSD-3-Clause, see file
header for attribution) — used to test an AI coding agent
([GitOps AI Platform](https://github.com/JawadAliAI/GitOps-AI)) against
realistic code, without touching the real scikit-learn repository.

- `random_state.py` — the real `check_random_state` helper.
